# Legacy

Completed-work narratives and superseded guidance. Nothing here is current truth. Documents are
kept because they record *what was true at a point in time* — useful when reading old commits or
wondering why a structure looks the way it does.

Every document here carries `status: archived` and is excluded from the routing index.

Nothing here should be followed as a procedure. If a reader needs the current answer, the root
[`CLAUDE.md`](../../CLAUDE.md) index points at it.

## Rules

- Move a document here instead of deleting it when the content was once accurate. Deletion is for
  content that was always wrong.
- Set `status: archived` and name the replacement in the table above, so a reader who lands here
  from a search knows where to go.
- Do not edit archived documents to "correct" them. A corrected history is worthless as evidence.
